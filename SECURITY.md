# Security

Report suspected vulnerabilities privately to contact@rez1.dev. Include reproduction steps and the affected revision. Do not include credentials or private repository contents.

The current website is static and does not execute agent tasks, accept API keys, or store submissions. Email links open your own email application. The page loads fonts from Google Fonts.

Security controls described in docs/ARCHITECTURE.md are requirements for future implementation, not claims about an existing runtime. Do not use a future experimental agent runtime with sensitive repositories until its execution boundaries have been implemented and reviewed.
