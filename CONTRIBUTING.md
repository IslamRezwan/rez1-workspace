# Contributing

The project is at the foundation stage. Read docs/MVP.md before proposing implementation work.

Open a proposal at https://github.com/IslamRezwan/rez1-workspace/issues or email contact@rez1.dev. Keep contributions focused on one concrete improvement. Do not introduce cloud execution before the local task-to-review workflow is validated.

For website changes:

1. Serve the dist directory using the command in README.md.
2. Check desktop and narrow mobile layouts.
3. Navigate the page by keyboard. Test the workflow tabs with arrow keys, Home, and End.
4. Verify links and distinguish existing functionality from planned features.
5. Include a concise explanation and relevant validation in the pull request.

Never commit API keys, environment files, user repositories, or real task output containing private information.
